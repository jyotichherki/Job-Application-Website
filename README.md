
# Job Application Website

## About
A responsive corporate recruitment platform
that allows candidates to explore job opportunities
and submit job applications.

## Features
- Search and filter job listings
- Expandable job descriptions
- Application form
- Resume upload
- Input validation
- Success message
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Installation
1. Download or clone this repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.

Frontend Development Project
